# Функции, декораторы и функции как объекты

## Декораторы
 **Декоратор** — это вызываемый объект, который получает декорируемую функцию и 
 возвращает объект, которым будет заменено её имя. 
 Обычно возвращают функцию-обёртку:
```
def decorator(func):
    def wrapper():
        return func()

    return wrapper
```
------
Но это не строгое требование. Декоратор может вернуть другой вызываемый объект или даже невызываемое значение, хотя последнее сделает обычный вызов декорированного имени невозможным.
Поэтому декораторы — не отдельный магический механизм выполнения функций. Они основаны на обычных возможностях Python:
1. Функции являются объектами.
2. Функции можно передавать в другие функции.
3. Функции могут возвращать другие функции.
4. Вложенные функции могут сохранять доступ к переменным внешней функции через замыкания.
Итог: декоратор нужен тогда, когда ты хочешь централизованно добавлять одинаковое поведение к разным функциям, не дублируя код и не изменяя их основную логику.
------
Декоратор применяется в момент выполнения определения функции, а не при каждом её вызове.
